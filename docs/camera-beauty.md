# 摄像头 + 美颜（规划，未实现）

在 Agent 面板旁边（或单独一个小窗）显示本地摄像头画面，带基础美颜，直接给 OBS 窗口捕获用。

## 方案

```
getUserMedia(720p30) ─▶ <video>（不显示）─▶ WebGL2 着色器管线 ─▶ <canvas>（显示，圆角 + 柔光边框）
                                              │
                                              └─ 可选：MediaPipe 人像分割 → 背景虚化
```

| 效果 | 做法 | 成本 |
|---|---|---|
| 磨皮 | 双边滤波（或导向滤波），只作用于肤色区域（YCbCr 肤色掩码） | 1 个 pass，720p 下 GPU < 1 ms |
| 美白 / 提亮 | 对亮度做 log 曲线，保留高光 | 合并进上一 pass |
| 红润 | 肤色区域轻微提升 R、降低 B | 同上 |
| 锐化 | USM，补偿磨皮丢掉的眼睛/头发细节 | 1 个 pass |
| 背景虚化（可选） | MediaPipe Selfie Segmentation（WASM + WebGL，~2 MB 模型） | 约 5~8 ms/帧，按需开 |

## 性能约束

- 这一块要 GPU：摄像头窗口单独开启硬件加速是做不到的（Electron 的 GPU 开关是进程级的），
  所以开摄像头时提示用户切换到"GPU 加速"模式（托盘菜单已有开关）。
- 帧率锁 30，用 `requestVideoFrameCallback` 驱动，不用 rAF 空转；窗口隐藏时停止取帧并释放摄像头。
- 720p 处理、按窗口实际尺寸输出，不做 1080p 中间缓冲。
- 关闭面板即 `track.stop()`，摄像头指示灯熄灭。

## 隐私

- 首次打开弹系统权限；所有处理在本机完成，不上传。
- 面板上常驻一个"摄像头已开启"的小红点。

## 里程碑

1. 原始画面 + 圆角柔光窗口；
2. 磨皮 / 美白 / 红润三个滑杆；
3. 背景虚化；
4. 与 Agent 面板组合布局（左下角：上摄像头、下组件）。
